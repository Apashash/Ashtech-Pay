---
name: Preserve existing icons
description: Keep the existing icon artwork unless the user explicitly asks for a replacement.
---

Do not replace or change an existing icon unless the user explicitly asks. When asked to improve an icon, preserve its original artwork and adjust only what is needed for legibility or presentation.

**Why:** The user explicitly said to keep existing icons and improve them rather than changing them.

**How to apply:** For contrast issues in dark mode, adjust the existing asset's CSS/filter or surrounding presentation; do not substitute a different symbol.
