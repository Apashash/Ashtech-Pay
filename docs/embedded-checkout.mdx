title: "Embedded checkout"

Embedded checkout est le chemin le plus rapide pour accepter un paiement. Votre serveur crée un lien, puis votre site ouvre le checkout AshTech Pay dans une fenêtre modale, sans rediriger la page du marchand.

## Clés nécessaires

Pour ce flux :

- `hp_live_...` est la **clé Checkout**. Elle reste sur votre serveur et authentifie `POST /api/v1/hosted-payment/create` ainsi que `GET /api/v1/hosted-payment/{payment_id}`.
- `ak_...` est la **clé Direct API**, séparée du checkout Hosted/Embedded. Elle sert aux endpoints `/v1/*`, comme `/v1/collect`.

Le navigateur du client reçoit uniquement le `payment_link`. Ne mettez jamais `hp_live_...` ou `ak_...` dans le code frontend.

## Créer un lien de paiement

Endpoint :

```http
POST https://www.ashtechpay.com/api/v1/hosted-payment/create
```

Authentifiez cette route avec votre clé `hp_live_...` :

<Tabs>
  <Tab title="Node.js">

```javascript
const orderId = "12345";

const response = await fetch(
  "https://www.ashtechpay.com/api/v1/hosted-payment/create",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.HP_LIVE_KEY}`,
      "Idempotency-Key": `order-${orderId}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      amount: 10000,
      currency: "XAF",
      description: `Commande #${orderId}`,
      is_fixed_amount: true,
      allowed_countries: ["CM"],
      notify_url: "https://example.com/webhooks/ashtechpay",
    }),
  },
);

const link = await response.json();
```

```php
$payload = [

    ],
    CURLOPT_POSTFIELDS => json_encode($payload),
]);

$link = json_decode(curl_exec($ch), true);
curl_close($ch);
```

## Ouvrir le checkout dans un popup

Ajoutez le script public une seule fois dans la page du marchand :

```html
<script src="https://www.ashtechpay.com/ashtechpay-checkout.js"></script>
```

Après avoir créé le lien côté serveur, ouvrez-le depuis un clic utilisateur :

```html
<button id="pay-button" type="button">Payer</button>

<script>
  document.getElementById("pay-button").addEventListener("click", function () {
    AshTechPayCheckout.open({
      paymentLink: link.payment_link,
      onSuccess: function (payment) {
        console.log("Paiement confirmé :", payment.reference);
        // Mettre à jour la commande côté marchand.
      },
      onFailure: function (payment) {
        console.log("Paiement échoué :", payment.reference);
      },
      onCancel: function () {
        console.log("Checkout fermé par le client");
      }
    });
  });
</script>
```

`AshTechPayCheckout.open()` accepte aussi `checkoutUrl`, `url` ou `slug`. Le popup est responsive et se ferme avec le bouton, la touche Échap ou le clic en dehors de la fenêtre. La redirection classique reste possible si le marchand préfère utiliser directement `payment_link`.

Ne créez pas le lien depuis le navigateur : la clé `hp_live_...` doit rester sur votre serveur.

### Éviter les liens en double

Envoyez une clé `Idempotency-Key` stable pour chaque commande. Le premier appel crée le lien ; les appels suivants avec la même clé et le même marchand renvoient le même `payment_link` et le champ `reused: true`.

```javascript
const response = await fetch(
  "https://www.ashtechpay.com/api/v1/hosted-payment/create",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.HP_LIVE_KEY}`,
      "Idempotency-Key": `order-${orderId}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      amount: 10000,
      currency: "XAF",
      description: `Commande #${orderId}`,
      is_fixed_amount: true,
    }),
  },
);
const link = await response.json();
```

Utilisez une clé différente pour une nouvelle commande ou une nouvelle session de paiement. La clé ne doit pas être générée aléatoirement à chaque requête.

## Prix fixe ou libre

- `is_fixed_amount: true` : `amount` est obligatoire et le client paie ce montant.
- `is_fixed_amount: false` : le client peut saisir le montant sur le checkout.
- `currency` accepte actuellement `XAF`, `XOF` ou `CDF`.
- `allowed_countries` est optionnel et contient des codes pays actifs comme `CM`.
