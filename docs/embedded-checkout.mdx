Embedded checkout est le chemin le plus rapide pour accepter un paiement. Votre serveur crée un lien, puis redirige le client vers la page AshTech Pay.

## Créer un lien de paiement

Endpoint :

```http
POST https://www.ashtechpay.com/api/v1/hosted-payment/create
```

Authentifiez cette route avec votre clé `hp_live_...` :

<Tabs>
  <Tab title="Node.js">

```javascript
const response = await fetch(
  "https://www.ashtechpay.com/api/v1/hosted-payment/create",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.HP_LIVE_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      amount: 10000,
      currency: "XAF",
      description: "Commande #12345",
      is_fixed_amount: true,
      allowed_countries: ["CM"],
      notify_url: "https://example.com/webhooks/ashtechpay",
    }),
  },
);

const link = await response.json();
```

  </Tab>
  <Tab title="Python">

```python
import os
import requests

response = requests.post(
    "https://www.ashtechpay.com/api/v1/hosted-payment/create",
    headers={

        "amount": 10000,
        "currency": "XAF",
        "description": "Commande #12345",
        "is_fixed_amount": True,
        "allowed_countries": ["CM"],
        "notify_url": "https://example.com/webhooks/ashtechpay",
    },

```

  <Tab title="cURL">

```bash
curl -X POST https://www.ashtechpay.com/api/v1/hosted-payment/create \
  -H "Authorization: Bearer hp_live_YOUR_HOSTED_PAGE_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 10000,
    "currency": "XAF",
    "description": "Commande #12345",
    "is_fixed_amount": true,
    "allowed_countries": ["CM"],
    "notify_url": "https://example.com/webhooks/ashtechpay"
  }'
```

  </Tab>
  <Tab title="PHP / Laravel">

```php
<?php

$payload = [
    "amount" => 10000,
    "currency" => "XAF",
    "description" => "Commande #12345",
    "is_fixed_amount" => true,
    "allowed_countries" => ["CM"],
    "notify_url" => "https://example.com/webhooks/ashtechpay",
];

$ch = curl_init("https://www.ashtechpay.com/api/v1/hosted-payment/create");
curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        "Authorization: Bearer " . getenv("HP_LIVE_KEY"),
        "Content-Type: application/json",
    ],
    CURLOPT_POSTFIELDS => json_encode($payload),
]);

$link = json_decode(curl_exec($ch), true);
curl_close($ch);
```

## Réponse

```json
{
  "status": "success",
  "payment_link": "https://www.ashtechpay.com/pay/hp-abc123",
  "payment_id": "transaction-or-link-id",
  "slug": "hp-abc123",
  "is_fixed_amount": true,
  "amount": 10000,
  "currency": "XAF",
  "allowed_countries": ["CM"],
  "expires_at": "2026-09-12T10:30:00.000Z"
}
```

Redirigez ensuite le navigateur du client vers `payment_link`. Ne créez pas le lien depuis le navigateur : la clé `hp_live_...` doit rester sur votre serveur.

## Prix fixe ou libre

- `is_fixed_amount: true` : `amount` est obligatoire et le client paie ce montant.
- `is_fixed_amount: false` : le client peut saisir le montant sur le checkout.
- `currency` accepte actuellement `XAF`, `XOF` ou `CDF`.
- `allowed_countries` est optionnel et contient des codes pays actifs comme `CM`.

## Vérifier le paiement

```http
GET https://www.ashtechpay.com/api/v1/hosted-payment/{payment_id}
```

```javascript

  },
);
```
