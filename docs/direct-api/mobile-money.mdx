## Créer une collecte

```http
POST https://www.ashtechpay.com/v1/collect
```

```javascript
const response = await fetch("https://www.ashtechpay.com/v1/collect", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.ASHTECH_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    amount: 1000,
    currency: "XAF",
    country_code: "CM",
    operator: "MTN",
    phone: "2376XXXXXXXX",
    reference: "order_12345",
    notify_url: "https://example.com/webhooks/ashtechpay",
  }),
});

const payment = await response.json();
```

## Données importantes

| Champ | Obligatoire | Description |
| --- | --- | --- |
| `amount` | Oui | Montant positif à collecter |
| `currency` | Oui | Devise du pays sélectionné |
| `country` | Oui | Code pays actif, par exemple `CM` |
| `operator` | Oui | Code opérateur renvoyé par `/v1/countries` |
| `phone` | Oui | Numéro international associé au wallet |
| `reference` | Oui | Référence unique de votre commande |
| `notify_url` | Non | URL HTTPS de votre webhook marchand |

<Warning>
  Ne déduisez pas le code opérateur à partir de la marque affichée à l'utilisateur. Utilisez le catalogue retourné par AshTech Pay pour envoyer la valeur attendue par l'API.
</Warning>

## Statut

Le traitement peut être asynchrone. Utilisez `GET /v1/transaction/:id` pour vérifier une transaction, mais utilisez le webhook pour déclencher votre fulfillment.

Pour les parcours USSD Push, Wave, OTP SMS et OTP USSD, consultez [les flux de paiement détaillés](/docs/direct-api/payment-flows).

```bash
  curl https://www.ashtechpay.com/v1/transaction/TRANSACTION_ID \
  -H "Authorization: Bearer $ASHTECH_API_KEY"
```
