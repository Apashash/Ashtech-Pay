Le Skill complet reste hébergé sur le serveur officiel AshTech Pay. Vous ne
devez pas copier plusieurs pages de texte : copiez simplement la commande
ci-dessous dans votre agent de programmation.

## Installer tous les Skills AshTech Pay

```bash
npx skills add https://doc.ashtechpay.com --all
```

Cette commande demande à l'outil officiel `skills` de télécharger et
d'installer tous les Skills publiés par `doc.ashtechpay.com` dans l'agent
détecté.

<Note>
  Le Skill principal est servi par
  [https://doc.ashtechpay.com/skill.md](https://doc.ashtechpay.com/skill.md).
  L'option `--all` permet d'ajouter aussi les nouveaux Skills publiés plus tard
  sur le même serveur.
</Note>

## Installer uniquement le Skill AshTech Pay

Si vous ne voulez installer que le Skill principal :

```bash
npx skills add https://doc.ashtechpay.com --skill ashtech
```

## Ce que le Skill installe

Une fois installé, l'agent dispose des règles officielles AshTech Pay pour :

- inspecter le langage, le framework et l'architecture du projet ;
- choisir Hosted Checkout, Direct API, Mobile Money, crypto ou webhooks ;
- garder les clés et secrets côté serveur ;
- vérifier une transaction avant de créditer ou livrer une commande ;
- rendre les webhooks idempotents ;
- tester les erreurs, les statuts pending/completed/failed et les doublons.

## Crypto incluse

Le Skill distant inclut aussi le parcours crypto complet :

- chargement de `GET /v1/crypto/assets` ;
- création avec `POST /v1/crypto/collect` ;
- champs obligatoires `customer.email`, `customer.firstName` et
  `customer.lastName` ;
- utilisation exacte de l'`asset_code`, du réseau, de l'adresse et du
  `memo/tag` retournés ;
- vérification serveur et webhook avant tout crédit ;
- expiration serveur documentée pour les paiements crypto `pending` ;
- interdiction d'inventer une monnaie, un réseau ou un endpoint.

<Warning>
  La commande nécessite un agent compatible avec l'outil `skills`. Si votre
  agent ne le prend pas encore en charge, donnez-lui directement l'URL
  [https://doc.ashtechpay.com/skill.md](https://doc.ashtechpay.com/skill.md) et
  demandez-lui de la lire avant d'intégrer AshTech Pay.
</Warning>
