Voici la version corrigée du passage, formulée comme une instruction claire que je donne à Replit pour implémenter la fonctionnalité dans Ashtech Pay :

⸻

Configuration Hosted Page dans le Dashboard

Dans le dashboard marchand, l’utilisateur doit pouvoir configurer la Hosted Payment Page depuis la section API.

Le fonctionnement doit être le suivant :
	1.	L’utilisateur ouvre son dashboard Ashtech Pay.
	2.	Dans la sidebar, il clique sur API.
	3.	Ensuite il clique sur Hosted Page.

Quand l’utilisateur ouvre la page Hosted Page, afficher un formulaire simple où il doit entrer les informations suivantes :

Success Redirect URL

URL vers laquelle le client sera redirigé après un paiement réussi.

Cancel Redirect URL

URL vers laquelle le client sera redirigé si le paiement échoue ou est annulé.

⸻

Génération des clés

Sous ces champs, ajouter un bouton :

Generate API Keys

Lorsque l’utilisateur clique sur ce bouton :
	1.	enregistrer les URLs de redirection
	2.	générer automatiquement les clés suivantes :

pk_live_xxxxxxxxx
sk_live_xxxxxxxxx
hp_live_xxxxxxxxx

Les clés doivent apparaître dans une section API Keys avec un bouton copy pour chaque clé.

⸻

Bouton vers documentation

Sous la section des clés générées, ajouter un bouton :

Documentation

Ce bouton doit rediriger vers une page Hosted Page Documentation.

⸻

Page Hosted Page Documentation

Cette page doit expliquer comment intégrer la Hosted Payment Page API.

La documentation doit inclure :

Authentication

Utiliser la clé :

hp_live_xxxxxxxxx


⸻

Création d’un lien de paiement

Endpoint :

POST /api/v1/hosted-payment/create

Headers :

Authorization: Bearer hp_live_xxxxxxxxx
Content-Type: application/json


⸻

Exemple de requête

{
  "amount": 5000,
  "currency": "XAF",
  "description": "Paiement commande #123"
}


⸻

Réponse API

{
  "status": "success",
  "payment_link": "https://pay.ashtechpay.top/pay/abc123",
  "payment_id": "pay_987654"
}


⸻

Fonctionnement final

Le flux doit être :

Dashboard Ashtech Pay
↓
Sidebar → API
↓
Hosted Page
↓
Entrer Success URL et Cancel URL
↓
Cliquer Generate API Keys
↓
Clés générées :

pk_live_xxxxxxxxx
sk_live_xxxxxxxxx
hp_live_xxxxxxxxx

↓
Bouton Documentation
↓
Page Hosted Page Documentation
↓
Le développeur peut utiliser l’API pour générer un lien paiement
↓
Le client ouvre le lien
↓
Page paiement Ashtech Pay
↓
Paiement
↓
Redirection vers le site marchand
