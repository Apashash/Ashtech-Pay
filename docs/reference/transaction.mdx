---
title: "GET /v1/transaction/:id"
description: "Consultez le statut d'une transaction."
---

```http
GET https://www.ashtechpay.com/v1/transaction/{transaction_id}?user_id=VOTRE_USER_ID
```

Utilisez l'identifiant renvoyé par la création de paiement et le `user_id` du profil AshTech Pay associé à la clé Bearer. Un `user_id` manquant renvoie `400 user_id_required`; un identifiant qui ne correspond pas au propriétaire de la clé renvoie `403 user_id_mismatch`. Les statuts peuvent inclure :

- `pending` : le paiement est encore en traitement ;
- `success` : le paiement est confirmé ;
- `failed` : le paiement a échoué.

<Warning>
  Une requête réussie signifie que la transaction a été trouvée, pas nécessairement qu'elle est payée. Vérifiez toujours le champ `status`.
</Warning>
